# My Journey of Learning Blender and 3D Modeling

I started learning Blender because I was interested in 3D art and wanted to create my own models. At first, Blender was difficult because it had many buttons, tools, and shortcuts. However, I watched beginner tutorials and practiced step by step.

## My First Steps

First, I learned how to move around the 3D space. I also learned how to move, rotate, and resize objects. These basic skills helped me understand how Blender works.

## My First Projects

I started modeling with simple shapes such as cubes, spheres, and cylinders. My first projects were a car and a cup. They were not perfect, but I was happy when I finished them. These projects helped me learn more about 3D modeling.

Later, I learned how to use Edit Mode and tools such as extrude, inset, and bevel. These tools helped me change shapes and add more details to my models. I also started learning how to add simple colors and materials.

## Challenges and Progress

Sometimes, I make mistakes or find it difficult to create the shape I want. I am not confident with Blender yet, but I continue to practice. I know that learning 3D modeling takes time and patience.

## My Future Goals

In the future, I want to improve my skills and create better models. I also hope to learn more about animation, lighting, and other Blender tools. My learning journey is still beginning, and I am excited to continue.
